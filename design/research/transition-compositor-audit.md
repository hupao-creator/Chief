# Chief macOS 转场的逐帧工作由谁承担

**优先验证对话内「当前页 ↔ 历史页」的整页纵移。** 这条产品路径每个显示回调都在主线程写一次 SwiftUI 状态，两页的中间姿态却只需要一个共同的 Y 位移。Report 的执行页已经有同形的双页 Core Animation 实现。若希望以更小改动先消掉一个持续时钟，选执行摘要文字上的扫光。Chief Bar 换列、Agent/Report 外层阅读面板都已提交原生图层动画；在这两处更值得区分的是「点击后迟迟没动」和「开始以后走不动」。

## 实测范围与验证方法

**本次双轨窗口实验。** 结论是固定内容的纵向平移适合下一步在真实历史页试做。相同的 200 px 行程、420 ms 时长、同一条 (0.42, 0, 0.58, 1) 曲线、同一个 320 × 200 非激活窗口。左半由主 run loop 的屏幕 display link 调用生产的 `NativeReadingPageTiming.sample` 后写模型位置；右半一次性提交 `CABasicAnimation(transform.translation.y)`，使用生产的 `replacementTimingFunction`。左轨也用图层显示，唯一需要应用持续推进的是左轨的坐标。两轨都是白色矩形，未挂载 SwiftUI 页面或 TextKit。
