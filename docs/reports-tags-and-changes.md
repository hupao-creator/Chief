# Find related work and check file changes

## Group tasks with tags

**Tag Agent** uses conversation titles to group unarchived tasks within each project folder. Each folder can have up to five tags. Tasks without a project folder share a separate set of up to five Inbox tags. In Overview, choose a folder to see its tags on the left, or choose an Inbox tag directly at the top. Existing tags stay available while Tag Agent is off, and sorting resumes when you turn it back on. [Find a task by folder or tag](overview.md#find-a-task-by-folder-or-tag) · [Set up Tag Agent](settings.md#set-up-tag-agent-and-super-thread-agent)

## See the work behind a Super Thread

A **Super Thread** is a report that **Super Thread Agent** puts together from completed work in the same project folder. Its card shows up to three lines of the introduction, including when you browse a collection. Click the card to read the report, then open **Related executions** if the list is closed. If Super Thread Agent updates the report while you’re reading, the new content appears in the open report and the related list stays where you left it.

A Super Thread can cite one run per source conversation. Each related card shows that run's title, a reply excerpt, and its duration when available. The status tells you how the source conversation is doing now.

Click the related card to open the source conversation's latest run beside the Super Thread. It may be newer than the cited run or still in progress. Use **Conversation contents** on the left edge of the source conversation to switch between its current run and earlier runs. The Super Thread stays open beside it. When you follow a link in a reply from Chief, a visible collection containing the Super Thread turns to its page before it opens. The side panel opens at the top of the run named in the reply, even if the related card cites a different run. If a related card fails to open, click it again to retry. The list shows when a conversation or run is unavailable.

When the source conversation opens on the right, the compact input bar glides beneath it and expands. Use it to write a follow-up for the run you’re viewing. When you send from a finished run, the side panel turns directly to your follow-up. Its title is the message you sent, with a status such as **Connecting to Codex** below it. The input stays beneath the panel, so you can start typing your next message. If the agent rejects the follow-up, Chief returns to the source run and restores the message above any text you added.

If the run is active, your message and its timestamp slide gently into place beside the report. With Reduce Motion on, the message appears in place. If you switch runs before sending, select the same run again to pick up your draft. Click **Back to related executions** to see the cards and their available excerpts together. The bar folds and glides back to the center. If the excerpts are still loading, the list shows Chief’s skillet until the cards are ready.

When you close the report with a source conversation open, the input bar folds beneath that conversation with the agent logo still visible. The compact bar stays in place while the logo flips back to Chief’s eyes. If the report card is still visible, the report then shrinks back to it. If reading the report removed it from **Unread**, the report and side panel fade together as soon as you close them. With Reduce Motion on, the mark changes directly. The bar returns to the center of Overview. With motion on, it moves horizontally first, then rises to its resting height. Click the report’s **×** to return to Overview.

## Browse Super Threads in a collection

A collection shows one Super Thread at a time and can turn pages automatically. To choose a Super Thread, move the pointer over the card and use the arrows or the page menu in the glass capsule over the cover. Collections of up to seven Super Threads also show a clickable marker for each page. Below the cover, the title, introduction and emoji look the same as on an individual Super Thread card. Click the card to read the displayed Super Thread. Use **Close Super Thread** in the reader to return to Overview.

To browse all members, click the page count in the upper-right corner of the collection card. The cards start near the top of a rounded glass panel. Widen the window to see more cards side by side, or scroll down to see the rest. Click a Super Thread to read it. The reader expands from the card you chose and may show Chief’s skillet while the report loads.

Click the reader’s upper-left arrow, **Back to Super Thread Collection**, to return to your place in the grid. You can read another member from there. The grid’s **Close** button stays in the upper-left corner as you scroll. In a narrow panel, the cards form one column below it. Click **Close** or press **Esc** in the grid to return to Overview. Any regrouping caused by reading those members takes effect when you close the grid.

When you return to Overview, two or more Super Threads in your current view can share a collection once each has been idle for 30 minutes. The time starts when you close a report, or when it was created if you have never opened it.

After a quick look at a Super Thread, its cover stays selected if it is still in the collection. Spending time reading a Super Thread or its source conversations, or returning to it within a day, gives it a better chance of appearing as an individual card. A Super Thread grouped to make room reappears on its own when the cards fit, including after you resize the window or archive another card.

## Archive a Super Thread

Right-click a Super Thread card and choose **Archive Super Thread**. In the list of all reports in a collection, you can also click the archive button on the card’s upper-right corner.

The Super Thread and its linked task conversations disappear from Overview. Their records stay saved and any work already running continues.

When archiving leaves the collection open, the archived card briefly fades away. If fewer than two Super Threads remain in the collection, the panel closes and any remaining Super Threads appear as individual cards in Overview.

## Check Git changes on a task card

For tasks in projects that use Git, the card can show the branch, number of changed files, and lines added or removed. These figures describe the working folder the task uses. Several tasks using the same folder can show the same changes. The summary is hidden when both line counts are zero. If files changed but Chief couldn't count the lines, the card shows that the count is unavailable.

Click the card to open the conversation and ask the agent about its changes.
